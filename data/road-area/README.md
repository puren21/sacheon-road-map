# 실폭도로 (도로경계 면)

## 현재 상태 — 2026-11-18

UI와 렌더러는 구현되어 있으나 **공식 원본 미확보로 실제 도로면 자료는 미등록**이다.
`manifest.json.available=false`는 이를 명시한다. 빈 데이터나 중심선 버퍼를 실폭도로로 제공하지 않는다.

공식 출처: https://www.vworld.kr/dtmk/dtmk_ntads_s002.do?svcCde=MK&dsId=30179

공식 화면 확인 결과:

- 국토지리정보원 연속수치지형도 `도로경계_면`, 전국, SHP, EPSG:5179, 연간 갱신, CC BY.
- 구축 레이어 정보 0건. 이 데이터셋에서 사용 가능한 API 레이어는 확인되지 않았다. API 키만 넣으면 사용 가능하다고 가정하지 않는다.
- 2026-10-01 갱신 전국 파일 `도로경계_면_001.zip` (738 MB), `_002.zip` (944 MB).
- 다운로드 버튼 클릭 시 “로그인 후 이용해주세요.” 확인. 로그인이나 원본 파일이 필요하다.
- 검색에 남아 있는 과거 경남 파일 `downloadResourceFile.do?ds_id=30179&fileNo=7`은 HTTP 200이나 본문 0바이트로 내려왔다. 최신 파일로 취급하면 안 된다.

## 원본 확보 후 처리

공식 사이트에서 두 분할 파일을 내려받고 압축을 풀어 해당 도로경계 면 SHP와 .prj/.dbf/.shx를 함께 보존한다. 전국 파일 자체를 저장소에 올리지 않는다.

Python 환경에 `geopandas>=1.0` 및 `shapely>=2.0` 설치 후, 저장소 루트에서:

```sh
python3 scripts/build-road-area.py /path/part001/A0010000.shp /path/part002/A0010000.shp --version 2026-10-01
```

실제 파일 경로를 사용한다. 스크립트는 저장소의 `City Boundary.geojson`에서 사천시(48240)를 찾아 정확한 경계로 자른다. EPSG:5179에서 0.3m 단순화 후 시 경계로 다시 자르고 WGS84로 변환한다. 0.01도 격자로 분할하고 속성은 제거한다. 원본 데이터 처리 실행은 아직 검증하지 못했다. 경계·홀·다중면, 섬 지역, 도로 누락, 산출 크기를 검토한 뒤 결과를 커밋해야 한다. 좌표계 없는 자료와 비어 있는 결과는 오류로 종료한다.

## 성능·동작

- 매 접속 기본 OFF. OFF 중 자료 요청/도형 생성 없음.
- ON이면서 Kakao level 4 이하에서만 manifest 및 현재 화면 타일을 지연 로딩.
- 지도 이동/확대 시작 때 기존 도형 즉시 분리, 진행 요청 취소. idle 180ms 후 갱신.
- 순차 타일 요청, 타일 사이 이벤트 처리 기회 제공, 최대 24개 타일 메모리 LRU + 브라우저 HTTP 캐시.
- 데이터 내용 해시를 타일 URL 버전으로 사용. 한 화면 최대 16타일, 400면, 40,000정점. 초과하면 부분 표시를 제거하고 확대 안내.
- Polygon 홀을 보존하며 기존 노선/편집 데이터는 수정하지 않음. OFF 시 모든 도형 제거.
- Kakao SDK 실패 시 토글을 비활성화하고 원인 안내. 저사양 PC 실제 FPS 및 모바일 실기기 성능은 미측정.

새 테스트 5개: 기본 OFF/축척 제한, ON/OFF 및 홀/캐시, 로딩 중 OFF, 자료 미등록 안내, 실패 후 재시도.

로컬 브라우저에서 메뉴 진입과 기본 OFF 확인. 카카오 SDK 응답 실패로 실제 도로 표시·지도 조작·모바일 화면 검증은 미완료. 공식 원본 다운로드가 로그인으로 막혀 실제 자료 클립 및 연결도 미완료.
