# 사천시 용도지역 WMS

공식 문서: https://www.vworld.kr/dev/v4dv_wmsguide2_s001.do

- WMS 1.3.0 `https://api.vworld.kr/req/wms`
- 공식 GetCapabilities에서 확인한 레이어와 스타일: `lt_c_uq111` 도시지역, `lt_c_uq112` 관리지역, `lt_c_uq113` 농림지역, `lt_c_uq114` 자연환경보전지역.
- EPSG:3857, BBOX x/y 순서, 투명 PNG. 2026-11-18 사천 지역의 실제 PNG 응답 확인.
- 현황 도로나 도시계획도로 자료를 포함하지 않는다.

## 키 설정

레이어 → 용도지역 → 브이월드 키 설정에서 API 키와 등록 서비스 URL을 입력하고 적용한다. 키는 sessionStorage에만 보관하므로 같은 탭의 새로고침에는 유지되고 새 세션에는 다시 설정해야 한다. 키를 저장소에 하드코딩하지 않는다. 설정 지우기로 제거할 수 있다. 운영 서비스 URL에 `https://puren21.github.io/sacheon-road-map/`를 등록해야 한다. 기본 DOMAIN은 `https://puren21.github.io`이며 필요하면 등록 정보에 맞게 변경한다. 설정을 적용해도 토글이 OFF이면 WMS를 요청하지 않는다.

## 표시·성능

매 접속 기본 OFF. ON 때 경계와 이미지를 지연 로딩한다. 한 화면당 용도지역 4종을 합성한 WMS 이미지 한 장을 요청하며 최대 1024px, canvas 최대 1440px로 제한한다. 디코딩 이미지 캐시 3개, 최대 10분. 이미지 저장이나 픽셀 읽기를 하지 않아 WMS 이미지 서버의 CORS 허용 없이 표시할 수 있다.

Kakao 지도의 투영법과 EPSG:3857 이미지의 차이는 16×16 격자의 삼각형 재투영으로 보정한다. canvas는 지도 좌표에 붙이고 이동 중에는 숨긴 후 idle 220ms 뒤 새 화면을 갱신한다. 같은 축척의 위치 갱신은 재투영을 반복하지 않는다. 클릭·터치는 통과시켜 기존 지도 조작과 편집을 유지한다. 축척 level 11보다 넓은 범위는 확대 안내. 이미지 실패·인증 오류·시간 초과를 화면에 안내하고 OFF/ON으로 재시도할 수 있다. OFF 중 진행 요청은 취소되고 늦게 도착한 응답은 붙이지 않는다.

`City Boundary.geojson`의 사천시(48240)만 사용한다. `scripts/build-zoning-boundary.py`(shapely 2.1.2)로 위경도 0.00001도(위도 기준 약 1.1m) 허용오차를 적용해 위상을 보존하며 경량화했다. 79개 구역과 홀을 보존하고 evenodd clip으로 사천시 밖을 가린다. 경계는 표시용이며 측량용 정합성을 보증하지 않는다. 타원체 투영 차이는 격자로 근사한다.

## 자동 검증

`node --test tests/*.test.cjs`: 100개 중 95개 통과, 기존과 동일한 5개 실패. 신규 WMS 테스트 11개 전부 통과: OFF/키 미설정 무요청, 4개 레이어·좌표축, 이미지 표시/제거·캐시, 지연 응답 무효화, 이동 취소/idle 병합, 오류 재시도, 키 변경, 축척·경계 범위, 경계 부속 구역/크기, 재투영 행렬.
