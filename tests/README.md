# 지도 성능 회귀 테스트

실행: `node --test tests/map-performance.test.cjs` (Node.js 18 이상).

현재 index.html에서 실제 함수를 읽고 Kakao 레이어와 이벤트·타이머를 모의 실행한다. 기본/축소 화면 level 7 이상에서 경계·명칭만 표시, level 6 이하에서 노선 표시, 축척 이탈·복귀, 수동 ON, 선택 완료 후 클릭 영역, 연속 idle 병합, 새 조작의 예약 취소, Windows/비 Windows 복원 분기, 스타일 캐시, 노선 필터와 OFF 노선 표시를 검증한다. 외부 패키지는 필요 없다.

2026-10-01: 35개 테스트 통과, 모든 인라인 스크립트 구문 검사 통과.

실제 브라우저 검증 한계: Mac의 내장 브라우저에서 localhost 페이지를 열었으나 “카카오 지도 SDK가 응답하지 않습니다” 메시지가 표시되어 실제 지도 조작과 프레임 속도를 확인하지 못했다. Windows Edge/Chrome 및 모바일 실기기 테스트를 수행한 결과는 아니다.

SDK가 허용된 주소에서 추가 확인할 항목:

- 기본 level 7에서 노선/노선번호 숨김 → level 6에서 노선 표시 → level 7 이상에서 노선 숨김과 읍면 경계/명칭 복원.
- 기타기능에서 읍면동 경계 ON 후 확대/축소·드래그 시 표시 유지, OFF 후 자동 규칙 복귀.
- 반복 휠, 확대 버튼, 모바일 핀치와 드래그 종료 후 라벨·노선 복원.
- 시도/농어촌도로 필터, OFF 노선 회색 표시, 노선 팝업, 스카이뷰, 읍면 선택, 거리/면적 측정.
- 노선 목록 스크롤 위치 및 메뉴 상태가 지도 조작으로 초기화되지 않는지 확인.

추가 성능 회귀 검증(모의 실행):

- 같은 노선 좌표를 100회 요청해도 `setPath`는 1회만 호출한다. 편집 강제 갱신과 상세도 변경은 반영한다.
- 같은 축척에서 기존 번호 위치가 화면 안에 있으면 100회 이동 갱신 동안 선분 탐색을 추가 실행하지 않는다. 확대/축소와 선형 변경 시 다시 계산한다.
- 같은 라벨 치수를 100회 요청해도 DOM 치수 측정은 1회다. 스타일·번호 변경 시 재측정하고, 0 크기는 저장하지 않는다.
- 겹쳐 숨긴 라벨은 다음 갱신에서 재부착하거나 크기를 재측정하지 않는다.

이는 중복 작업 횟수를 검증한 결과이며 실제 기기의 FPS나 처리 시간 개선율을 측정한 결과는 아니다.

읍면 경계 선형 데이터 검증:

- 초기 `township_overview.geojson`: 144,535바이트. 지도에는 간략화·중복 제거한 선만 표시하며, 함께 저장된 작은 폴리곤은 명칭 위치와 영역 클릭 계산에만 사용한다. 면/투명 클릭 폴리곤을 생성하지 않는다.
- 수동 ON 시 `township_detail_lines.geojson`를 한 번 읽어 원본 좌표의 선을 표시한다. 자동 간략 선과 원본 선은 동시에 붙이지 않는다.
- 원본 5,530,729바이트 대비 초기 경계 파일은 약 97.4% 작다. 초기 선분은 1,345개이며, 원본 고유 선분은 116,152개다.
- 원본에서 중복된 선분 7,041개를 제거했다. 원본 고유 선분 116,152개를 수동 표시 파일이 빠짐없이 포함하며, 두 선 파일 모두 중복 선분이 0개임을 테스트한다.
- 읍면 속성 보존, 내부 홀 클릭 제외, 원본 로드 중 OFF, 중복 요청 병합 및 실패 후 재시도를 검증한다.

데이터 재생성: `python3 scripts/build-township-boundaries.py`. 고정 버전 mapshaper 0.7.72로 공유 경계를 구성하고, 자동 표시용만 Douglas–Peucker 60m 간격으로 단순화(keep-shapes 및 교차 보정)한다. 수동용은 단순화하지 않는다. 원본 파일은 수정하지 않는다. npm 최초 실행에는 네트워크가 필요하다.

범례: 도로 유형별 색상·선 표시 상태·스카이뷰 색상 동기화와 동일 설정에서의 중복 DOM 생성 방지를 모의 실행으로 검증한다.

초기 전체 보기: 고정 level 7 대신 전체 읍면 경계에 `setBounds`와 여백을 적용한다. 화면 맞춤 결과(최소 level 7)를 자동 경계/노선 전환 기준으로 사용한다. 데스크톱·모바일·낮은 높이의 세 가지 화면에서 맞춤 호출 및 한 단계 확대 시 노선 표시를 모의 검증한다. 도로 로딩이 늦게 완료되어도 사용자 화면을 초기 위치로 다시 되돌리지 않는다.

범례 접기: 저장된 접힘 상태 복원, 반복 접기/펼치기, 접근성 속성 변경, 브라우저 저장소 차단 시 동작을 모의 검증한다.
