# 지도 성능 회귀 테스트

실행: `node --test tests/map-performance.test.cjs` (Node.js 18 이상).

현재 index.html에서 실제 함수를 읽고 Kakao 레이어와 이벤트·타이머를 모의 실행한다. 초기 level 7, 축척 이탈·복귀, 수동 ON, 선택 완료 후 클릭 영역, 연속 idle 병합, 새 조작의 예약 취소, Windows/비 Windows 복원 분기, 스타일 캐시, 노선 필터와 OFF 노선 표시를 검증한다. 외부 패키지는 필요 없다.

2026-10-01: 16개 테스트 통과, 모든 인라인 스크립트 구문 검사 통과.

실제 브라우저 검증 한계: Mac의 내장 브라우저에서 localhost 페이지를 열었으나 “카카오 지도 SDK가 응답하지 않습니다” 메시지가 표시되어 실제 지도 조작과 프레임 속도를 확인하지 못했다. Windows Edge/Chrome 및 모바일 실기기 테스트를 수행한 결과는 아니다.

SDK가 허용된 주소에서 추가 확인할 항목:

- 기본 level 7 → 확대/축소 → level 7 복귀 시 경계 제거/복원.
- 기타기능에서 읍면동 경계 ON 후 확대/축소·드래그 시 표시 유지, OFF 후 자동 규칙 복귀.
- 반복 휠, 확대 버튼, 모바일 핀치와 드래그 종료 후 라벨·노선 복원.
- 시도/농어촌도로 필터, OFF 노선 회색 표시, 노선 팝업, 스카이뷰, 읍면 선택, 거리/면적 측정.
- 노선 목록 스크롤 위치 및 메뉴 상태가 지도 조작으로 초기화되지 않는지 확인.
